# Steel Predictor App

## Описание проекта

Steel Predictor App — веб-приложение для прогнозирования механических свойств сталей на основе их химического состава с использованием методов машинного обучения.

Система позволяет выполнять прогнозирование основных механических характеристик как для углеродистых, так и для нержавеющих сталей. В качестве входных данных используются значения химического состава и технологические параметры обработки материала.

В основе системы лежат модели машинного обучения, обученные на открытых наборах данных, содержащих сведения о составе и механических свойствах различных марок сталей.

## Основные возможности

* прогнозирование предела прочности при растяжении (UTS);
* прогнозирование предела текучести (YS);
* прогнозирование относительного удлинения;
* прогнозирование твердости материала;
* поддержка углеродистых и нержавеющих сталей;
* сохранение истории прогнозов;
* отображение результатов через веб-интерфейс.

## Принцип работы

1. Пользователь выбирает тип стали.
2. Вводит химический состав материала.
3. Данные проходят предварительную обработку.
4. Выполняется масштабирование признаков.
5. Загружается соответствующая ML-модель.
6. Выполняется прогнозирование механических свойств.
7. Результаты отображаются пользователю и сохраняются в истории.

## Запуск проекта

Установка зависимостей:
pip install -r requirements.txt

Выполнение миграций:
python manage.py migrate

Запуск сервера:
python manage.py runserver

После запуска приложение доступно по адресу:
http://127.0.0.1:8000/
